安装器运行依赖

当前 Release：v1.0.0。Python 负责安装逻辑，Git 负责获取 RTT 代码；这些是安装阶段的工具，STM32 上运行的固件无需 Python。

  • Windows：PowerShell 5.1 / 7 + Python 3.8+ + Git。在线启动使用 PowerShell 内置下载命令。
  • Linux / macOS / POSIX：sh + Python 3.8+ + Git；使用下方一行下载命令还需要 curl，本地运行已下载的脚本无需 curl。
  • Python 无第三方包依赖。安装完成后的固件构建使用项目原有的 CMake、构建工具与 ARM 工具链；安装器不会调用编译器。
v1.0.0 两种安装模式的要求
安装模式需要 Git 命令项目需要 Git 仓库版本选择
submodule需要需要，根目录且已有提交tag / commit / latest，最终固定 commit
source · 纯源码需要，当前仍通过 Git 获取源码无需tag / commit / latest，记录实际 commit

纯源码无需 Git 仓库，但当前仍需安装 Git。v1.0.0 先克隆上游，再复制源码并移除 Git 元数据；尚不支持直接下载源码 ZIP、Release 附件或导入本地包。

从一行命令开始

当前两个模式均需要 Python 3.8+ 与 Git
在 CubeMX CMake 项目目录打开终端。不传参数 = 交互式安装，依次选择项目、RTT 版本、目录与安装模式。


为 Agent 生成安装命令
传入参数后不再提问。固定 RTT tag 或 commit，安装结果更容易复现。
命令固定安装器 v1.0.0。需要自定义 CMake 目标？追加 -Target 'your_target'。全部参数 ↗


01 / CHOOSE
版本由你选择
支持上游 tag、完整 commit SHA 与 latest。交互时列出可选版本，安装清单保存实际 commit 与源码哈希。
02 / INTEGRATE
适合你的源码管理
submodule 跟踪上游，纯源码便于交付。接入顶层 CMake，包含 RTT、printf 与 Config 头文件路径。
03 / REPEAT
放心交给 Agent
参数模式零提问，失败返回非零状态，成功输出 JSON。相同参数重复执行会检查现有安装，不会重复添加。


安装以后
重新 CMake configure / build，在应用的 USER CODE 区域加入：
#include "SEGGER_RTT.h"

SEGGER_RTT_WriteString(0, "Hello STM32!\n");
SEGGER_RTT_printf(0, "counter=%u\n", counter);
通过 J-Link RTT Viewer 等工具查看输出。SEGGER 官方文档 ↗
开始前确认
  • 项目包含 cmake/stm32cubemx/CMakeLists.txt。
  • 默认 submodule 模式要求项目是 Git 仓库根目录，且至少有一次提交；纯源码模式无需 Git 仓库。
  • 已存在的 RTT 目录或手工接入会被保护。v1 不提供自动迁移或原地升级。
  • Release 包含两个独立脚本和 SHA256SUMS，可先下载审阅及校验。
