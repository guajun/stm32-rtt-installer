不要使用 Middlewares 作为文件夹名。 这个目录由 CubeMX 管理，重新生成项目时可能被改动。推荐使用 SEGGER_RTT 或 DebugRTT；安装器会拒绝受保护目录。

安装器运行依赖

Python 3.8+ 是所有模式的安装运行时；只有 submodule 需要 Git。Python 负责安装逻辑与压缩包处理，STM32 固件无需 Python。

  • Windows：PowerShell 5.1 / 7 + Python 3.8+；submodule 另需 Git。
  • POSIX：sh + Python 3.8+；一行在线启动另需 curl，本地脚本无需 curl。
  • 无需额外解压软件或 Python 包：ZIP / pack 使用 Python 标准库处理，不需要 7-Zip、WinRAR、unzip 或 CMSIS Pack 管理器。

本地 .pack / .zip 安装完全离线。不支持本地目录、tar.gz、7z 或 RAR。pack 与 ZIP 均自动识别根目录或一层外层目录，保留许可证。后续固件构建使用项目原有 CMake 和 ARM 工具链。

01 / CHOOSE
版本由你选择
在线 ZIP 与 submodule 可选 tag / commit；pack 可选 Release。本地文件不查询网络，安装清单保存包与源码哈希。
02 / INTEGRATE
适合你的源码管理
submodule 跟踪 Git 上游；纯源码仅接收 pack 或 GitHub ZIP，支持线上与本地来源，不需要 Git。
03 / REPEAT
放心交给 Agent
参数模式零提问，失败返回非零状态，成功输出 JSON。相同参数重复执行会检查现有安装，不会重复添加。


安装以后
重新 CMake configure / build，在应用的 USER CODE 区域加入：
#include "SEGGER_RTT.h"

SEGGER_RTT_WriteString(0, "Hello STM32!\n");
SEGGER_RTT_printf(0, "counter=%u\n", counter);
通过 J-Link RTT Viewer 等工具查看输出。SEGGER 官方文档 ↗
开始前确认
  • 项目包含 cmake/stm32cubemx/CMakeLists.txt。
  • submodule 要求项目为已有提交的 Git 仓库根目录；pack / ZIP 安装不需要 Git 命令，也不需要 Git 仓库。
  • 已存在的 RTT 目录或手工接入会被保护。v1 不提供自动迁移或原地升级。
  • Release 包含两个独立脚本和 SHA256SUMS，可先下载审阅及校验。
