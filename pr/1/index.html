STM32 CUBEMX × SEGGER RTT INSTALLER

一键接入 RTT，
安心交给 CMake。

为 STM32CubeMX CMake 工程接入 SEGGER RTT。自动添加源文件与头文件路径，保护 CubeMX 管理目录，固定来源，并支持 Agent 非交互安装。

SEGGER_RTT_WriteString(0, "Hello!\n");
→ Your firmware, now talking.
不要使用 Middlewares 作为文件夹名。 这个目录由 CubeMX 管理，重新生成项目时可能被改动。推荐使用 SEGGER_RTT 或 DebugRTT；安装器会拒绝受保护目录。

运行前准备

所有安装方式需要 Python 3.8+，无第三方 Python 包依赖。Windows 使用 PowerShell 5.1 / 7；POSIX 使用 sh，在线一行启动另需 curl。

默认复制源码，无需 Git。选择 Git submodule 时才需要 Git，且项目须为仓库根目录、已有提交。后续构建使用工程原有的 CMake 与 ARM 工具链。

从一行命令开始

Python 3.8+ · 纯源码无需 Git / 额外解压软件
在 CubeMX CMake 项目目录打开终端。不传参数 = 交互式安装，依次选择项目、RTT 版本、目录与安装模式。


为工程生成安装命令
选择项目、安装方式和版本即可。传入参数后不再提问，适合 Agent 直接执行。






高级 / 离线安装
在线复制默认使用官方 GitHub 源码快照。只有需要离线文件、指定下载地址或项目定制时，才需要填写以下选项。
本地包完全离线，无需 Git 或外部解压软件。支持 pack 与 GitHub ZIP 的直接根目录或一层外层目录，不接受本地目录或其他压缩格式。


参数与安装行为说明 ↗


01 / CMAKE
接入正确的位置
添加 RTT 核心、printf 和 Config 头文件路径，在顶层 CMake 接入，保护 CubeMX 生成目录。
02 / PIN
来源明确，结果可查
正式版与 main 快照分开选择。安装时解析为具体 commit，清单记录 commit、包与文件哈希。
03 / AGENT
可重复交给 Agent
参数模式不提问，成功输出 JSON，失败返回非零状态；相同参数重复运行验证已有安装，不重复接入。


安装以后
重新 CMake configure / build，在应用的 USER CODE 区域加入：
#include "SEGGER_RTT.h"

SEGGER_RTT_WriteString(0, "Hello STM32!\n");
SEGGER_RTT_printf(0, "counter=%u\n", counter);
通过 J-Link RTT Viewer 等工具查看输出。SEGGER 官方文档 ↗
开始前确认
  • 项目包含 cmake/stm32cubemx/CMakeLists.txt。
  • submodule 要求项目为已有提交的 Git 仓库根目录；pack / ZIP 安装不需要 Git 命令，也不需要 Git 仓库。
  • 已存在的 RTT 目录或手工接入会被保护。v1 不提供自动迁移或原地升级。
  • Release 包含两个独立脚本和 SHA256SUMS，可先下载审阅及校验。
